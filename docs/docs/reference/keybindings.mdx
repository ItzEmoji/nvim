# Keybindings

{/* This page is generated by docs/scripts/render-keymaps.ts. Do not edit it by hand. */}

The leader key is `<Space>`. This page lists the 126 binds set through `vim.keymaps`, generated from the same Nix evaluation that builds the editor. Some plugins register their own mappings through their own submodules instead; those show up in the which-key popup (press the leader key in the editor) but not on this page. The popup is the complete reference — this page is its searchable offline copy of everything that comes from `vim.keymaps`.
